ISTRUZIONI PER L'AVVIO DEL CRM
-----------------------------

Il CRM può essere avviato in due modi:

**MODO BROWSER (consigliato):**
1. Usa il collegamento "Upersite CRM Browser.vbs" sul tuo Desktop.
2. In alternativa, fai doppio clic sul file "Upersite CRM Browser.vbs" in questa cartella.

**MODO DESKTOP (Electron):**
1. Fai doppio clic sul file "Avvia CRM.vbs" in questa cartella.

Entrambe le modalità si avvieranno silenziosamente in background senza mostrare finestre del terminale.
Non chiudere eventuali processi di node.js che vedi nel task manager se vuoi mantenere l'app aperta.

Note sulle Impostazioni:
-----------------------
- Puoi cambiare la password master dalle nuove "Impostazioni" (cliccando sui tre puntini ... in alto a destra).
- Troverai lì anche le opzioni per Esportare e Importare i tuoi dati.
